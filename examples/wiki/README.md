# Example Wiki

This is a fictional wiki showing optional frontmatter, ordinary links, citations,
and the four suggested type categories. Names, contact details, URLs, and events
are illustrative.

- [Website project](projects/website.md): an ongoing entity with a review deadline.
- [Alex Rivera](people/alex.md): a person and alternative lookup name.
- [Deployment guide](guides/deployment.md): a document about the project.
- [Project review](events/project-review.md): a particular meeting.
- [Studio](places/studio.md): a place referenced by the meeting.
- [Small releases](concepts/small-releases.md): a reusable principle.

This index deliberately has no frontmatter. Every Markdown file here is intended
to satisfy the document format; intentionally invalid examples belong in tests.
Use a temporary copy for move/index integration tests so the checked-in examples
stay unchanged. Select this directory as the wiki root when exercising the CLI.
